# H2. Scorecards

## A. Screening call scorecard (30 min, CEO or trusted advisor)

| Area | Question | What good sounds like | Score 0–4 |
|---|---|---|---|
| Attribution | "Walk me through the last three new clients you personally originated: how you found them, cycle length, ARR." | Specific, consistent, verifiable detail; names the trigger and the buyer; no vague "we" | |
| Recurring revenue | "What did your book look like in MRR/ARR terms and how did it change over your tenure?" | Thinks in recurring terms; knows churn and expansion | |
| Hunting system | "What does a normal Tuesday look like for your pipeline?" | Named cadence, numbers, channels | |
| Value selling | "When did you last lose on price, and what did you learn?" | Owns it; explains TCO framing; no blame | |
| Small-company fit | "What would you need from us that you have today and might not have here?" | Realistic about enablement; attracted by autonomy, not by resources | |
| Ambition | "Where do you want to be in three years?" | Builder path is specific (team, plan design) or honest IC preference | |
| Integrity | "How do you handle information you have about your current employer's customers?" | Clear boundary; will not bring lists or confidential data | |
| Economics | "What is your current OTE structure and what level of risk are you comfortable with?" | Candid; variable-heavy comfort for a Rainmaker | |

Advance if ≥ 24/32 with no integrity concerns.

## B. Rainmaker (archetype A) profile scorecard

| Attribute | Weight | Evidence required |
|---|---|---|
| Personally originated new ARR (last 3 years) | 30% | Reference-verifiable figures; ideally $500K–$1M+/yr |
| Quota attainment history | 20% | Awards, rankings, consistent >100% |
| Deal profile match ($50K–$500K ARR, 3–9 month cycles, owner/CFO buyers) | 15% | Examples |
| Prospecting self-sufficiency | 15% | Cadence, lists, referral network |
| MSP/MSSP fluency | 10% | Can explain stack, SLAs, onboarding, security baseline |
| SoCal network | 10% | Named relationships, associations, events |

## C. Builder (archetype B) profile scorecard

| Attribute | Weight | Evidence required |
|---|---|---|
| Personal selling record (still a producer) | 30% | As in A |
| Took a company from $X to $Y | 20% | Verified by references; attribution clarity |
| Hired and developed sellers | 15% | Names, ramp times, retention |

| Partner/referral channel building | 10% | Program results |
