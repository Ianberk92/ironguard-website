# H1. The Ultimate Sales Test — Interview Exercises and Scoring

Purpose: make it hard for a polished but ineffective salesperson to look exceptional. Every exercise is scored
against observable behaviors, 0–4 per criterion (0 = absent, 1 = weak, 2 = adequate, 3 = strong, 4 = exceptional
with evidence). Run exercises 1–6 live (60–75 minutes total, two Ironguard interviewers, one plays the prospect);
exercise 7 is a take-home presented live; exercise 8 is the reference process. A candidate must score ≥ 3 on the
starred (*) criteria to advance.

Ground rules for interviewers: play the prospect realistically (busy, skeptical, price-aware, not hostile). Do
not rescue the candidate. Score independently, then reconcile. Record verbatim examples.

---

## Exercise 1 — Executive Discovery (15 min)

Setup: You are the COO of a 120-person engineering firm with three offices. You have an incumbent MSP that
"answers tickets" but a recent cyber-insurance renewal asked for MFA and EDR evidence you could not produce.
You agreed to a 20-minute call because a peer mentioned Ironguard. You are not shopping.

Candidate task: run the first conversation.

| # | Criterion | 0–4 | Notes |
|---|---|---|---|
| 1* | Opens with context and a reason for the call tied to the prospect, not a pitch | | |
| 2* | Uncovers business pain (insurance exposure, onboarding failures, site growth) rather than technical symptoms | | |
| 3* | Quantifies impact (what a denied claim, a failed audit, or a day of downtime costs) in the prospect's words | | |
| 4 | Identifies decision process: who else, budget cycle, incumbent contract terms | | |
| 5 | Listens: talk ratio under 40%; paraphrases accurately | | |
| 6* | Earns a concrete next step with a date and attendees (e.g., Insurance Readiness Review or environment review) | | |
| 7 | Avoids over-promising or disparaging the incumbent | | |

Red flags: feature dumping; asking "what keeps you up at night"; proposing pricing before discovery; no next step.

## Exercise 2 — Competitive Displacement (10 min)

Setup: A 200-person construction company is 14 months into a 36-month agreement with a regional MSP; they are
"fine, not thrilled." Candidate explains, then demonstrates in a short role-play, how they would win the account.

| # | Criterion | 0–4 | Notes |
|---|---|---|---|
| 1* | Builds a multi-step campaign (land with a review/project, create proof, time the renewal) rather than a one-call close | | |
| 2* | Uses Ironguard's checkable commitments (published pricing, no lock-in after 90 days, client-owned credentials, written standards) as proof, accurately | | |
| 3 | Addresses contract-exit mechanics honestly (termination clauses, transition cost, data/credential handover) | | |
| 4 | Finds an internal champion and a trigger event (new site, insurance renewal, leadership change) | | |
| 5* | Never suggests inducing breach of contract or using the incumbent's confidential information | | |
| 6 | Shows patience with a 6–12 month horizon while creating interim value | | |

## Exercise 3 — Cold Prospecting (10 min)

Setup: Give the candidate a short list of five real-looking (fictional) North County companies with one line
each (industry, size, sites). Candidate picks one, explains why, and performs a cold call or writes a cold email
on the spot; then describes their weekly prospecting system.

| # | Criterion | 0–4 | Notes |
|---|---|---|---|
| 1* | Qualifies the list against Ironguard's ICP (50–500 people, multi-site, M365/GWS, security pressure) and explains the pick | | |
| 2* | Cold outreach is specific, short, relevant (names a plausible trigger), and asks for a small commitment | | |
| 3 | Handles the "we're all set" brush-off without arguing; offers a reason to stay in touch | | |
| 4* | Describes a repeatable weekly cadence (accounts, touches, channels, referral asks, events) with numbers | | |
| 5 | Shows how they research triggers (job posts, new sites, insurance renewals, leadership changes) | | |
| 6 | Mentions using existing assets (Scorecard, guide, Insurance Readiness Review) as door-openers | | |

## Exercise 4 — Financial Selling (10 min)

Setup: The CFO says: "Your proposal is $180 per user for 100 users. The other quote is $110. Convince me."

| # | Criterion | 0–4 | Notes |
|---|---|---|---|
| 1* | Reframes from price per user to total cost of ownership and risk (out-of-scope invoices, downtime, incident cost, insurance) | | |
| 2* | Asks what the $110 includes and exposes the coverage decisions behind a low quote (offshore-only, no security baseline, change-order model) | | |
| 3 | Uses credible, modest numbers; does not invent statistics | | |
| 4 | Ties price to the written commitments (same-day offboarding, restore validation, license reconciliation) and to CFO-readable reporting | | |
| 5* | Holds price without caving; offers scope options rather than discounts | | |
| 6 | Proposes a low-risk way to validate value (Insurance Readiness Review, 90-day initial term) | | |

## Exercise 5 — Objection Handling (10 min)

Prospect objections, delivered in sequence: "Our current provider is cheaper." "Switching is risky; last time
we changed vendors it was a mess." "There's no immediate need; let's talk next year."

| # | Criterion | 0–4 | Notes |
|---|---|---|---|
| 1* | Acknowledges and explores each objection before answering (asks what "risky" meant last time) | | |
| 2* | Answers with specifics from Ironguard's model (transition plan, documentation, 90-day term, client-owned credentials) without inventing claims | | |
| 3 | Creates honest urgency from the prospect's own facts (renewal date, open site, insurance deadline), not artificial pressure | | |
| 4 | Keeps composure; no defensiveness, no disparagement | | |
| 5* | Converts "next year" into a defined interim step with a date | | |
| 6 | Knows when to walk away or de-prioritize a poor-fit buyer | | |

## Exercise 6 — Closing (8 min)

Setup: Third meeting. The COO likes the plan; the CFO has questions; the CEO has not been involved. Candidate
must move the opportunity to a clearly defined next commitment.

| # | Criterion | 0–4 | Notes |
|---|---|---|---|
| 1* | Summarizes agreed pain, solution and value before asking for anything | | |
| 2* | Asks for a specific commitment (signed Insurance Readiness Review, environment review with CEO present, agreement review by date) | | |
| 3 | Surfaces and handles the CFO's open questions directly | | |
| 4* | Uses no deceptive pressure (fake deadlines, invented competitors, discount-for-today) | | |
| 5 | Names the mutual plan: steps, owners, dates through go-live | | |
| 6 | Reads a "soft yes" correctly and tests it ("What would stop this from happening by the 30th?") | | |

## Exercise 7 — First 90 Days (take-home, 20-min presentation)

Prompt: "Show us how you would build an initial pipeline and win business for Ironguard IT in your first 90
days." Provide the website, the pricing page and the ICP. No access to internal data.

| # | Criterion | 0–4 | Notes |
|---|---|---|---|
| 1* | Realistic targets (pipeline, first meetings per week, first signatures in month 3–4) consistent with the economics model | | |
| 2* | Named target segments and a method for building lists (triggers, referrals, associations, local events) | | |
| 3 | Uses Ironguard assets and proposes concrete improvements (case studies, reviews, offers) | | |
| 4 | Defines what they need from the CEO and the engineering team (co-selling, scoping SLAs, references) | | |
| 5* | Shows a weekly operating rhythm and metrics they will report | | |
| 6 | Identifies risks (delivery capacity, brand, references) honestly and proposes mitigations | | |
| 7 | Quality of thinking about Builder topics (CRM, comp, hiring) if applying as Builder | | |

## Exercise 8 — Track Record Verification

See `03_reference_check_guide.md`. Scored on consistency between claims and references (0–4 per claim), with
any material discrepancy on personally-originated revenue treated as disqualifying.

## Aggregate scoring

| Component | Weight |
|---|---|
| Ex. 1 Discovery | 15% |
| Ex. 2 Displacement | 10% |
| Ex. 3 Prospecting | 15% |
| Ex. 4 Financial selling | 15% |
| Ex. 5 Objections | 10% |
| Ex. 6 Closing | 10% |
| Ex. 7 First 90 days | 10% |
| Ex. 8 Track record verification | 15% |

Advance to offer discussion: weighted score ≥ 70%, all starred criteria ≥ 3, no integrity flags. A candidate who
is charming but scores < 3 on criteria 1.3, 3.4, 4.1 or 6.2 is not a rainmaker; do not proceed on charisma.
